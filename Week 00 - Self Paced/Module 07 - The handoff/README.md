# Module 07 — The handoff

The program map is [README.md](../../README.md). This module is part of [Week 00 — Self Paced](../README.md).

Leave the service with the two people who have to live with it. One scope, two pages, one runbook, and an owner note. The pilot does not start until a clinical safety owner is named.

**Time.** About half a day.
**Who.** [target_audience.md](../../target_audience.md). The two readers below are the client's readers, not the participants.
**Your work.** Read the reference pack in [handoff](../handoff) and be able to defend each page.
**Done when.** The checker passes, and you can give the same three sites, the deferred list, the signer, and the reason the pilot stays stopped.
**Pack.** [handoff](../handoff)
**Check.** `python -m course screening_handoff.check` from `Week 00 - Self Paced`. No model call.

## Sequence

| | Note | What you do |
|---|---|---|
| 1 | [Two audiences](01-two-audiences.md) | Hold both pages to one scope. |
| 2 | [The executive page](02-the-executive-page.md) | Say what the ministry can be shown, and what is deferred. |

| 4 | [The runbook](04-the-runbook.md) | Start, log, failure, and what the service will not do. |
| 5 | [The owner](05-the-owner.md) | No named safety owner means the pilot does not start. |
| 6 | [Check](06-check.md) | Run the checker. |
