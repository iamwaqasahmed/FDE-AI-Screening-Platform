# Patient Access Assistant starter

This is the Week 1, Day 1 template. It lives with the [day notes](../README.md). The build copies it into `data/rel-w1d1/starter`. Do the lab in `Week 01/Day 01/work`, not in this folder.

From this folder:

```text
python -m unittest discover -s tests -q
python scan.py
```

Copy `credentials/dev.json` from the kickoff pack into `credentials/` before you treat the scan as complete. That folder is gitignored. The sample referral letter stays out of this folder.
