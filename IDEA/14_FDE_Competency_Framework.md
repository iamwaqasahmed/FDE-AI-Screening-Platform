# 14 — Competency framework

A graduate can do these on a system they have not been walked through. The evidence is the binding and the cumulative checks.

| Capability | Investigation | Evidence |
| --- | --- | --- |
| Separate a claim from a record | INV-01, INV-02 | A claim id is not used as a clock or a decision |
| Name the authority of a displayed number | INV-01 | Holdout and mini-world |
| Refuse a collapsed decision | INV-02 | `dec-clinical` unchanged by a letter |
| Put a check inside the tool | INV-03 | Document-sourced id does not book |
| Make a side effect idempotent across channels | INV-04 | One logical effect under replay, crash, and file |
| Cite only an authorized, current clause | INV-05 | Hash and audience |
| Measure without seeing the label | INV-06 | No-call on the fixture |
| Page on the user-visible fact | INV-07 | Stale document fails a healthy host |
| Class bytes and read a processor record | INV-08 | Restricted fixtures absent; regions compared |
| Transfer the questions | INV-09 | New nouns |
| Say what a managed service does not guarantee | INV-04, INV-08 | Template and the business key |
| Hand a person a usable next step | INV-09 | Handoff fields present, no invented clinical grade |

They are not certified in a statute, a cloud provider, or a clinical specialty.

The optional recording, when a reviewer exists, uses the same two points as [the learning design](13_Self_Paced_Learning_Design.md). It is not a hidden eleventh investigation.
