# 5 — Engineering challenges

Each challenge is one investigation. The demo can be passed by the naive move. The holdout cannot.

| Id | Challenge | Naive move the demo rewards | What the holdout requires |
| --- | --- | --- | --- |
| INV-01 | The published wait matches the warehouse | Recompute the mart | Bind the screen to the authority the label promises. Always discarding the warehouse fails when a later label really is the hospital series |
| INV-02 | One field called urgency | Classify the letter into that field and add a disclaimer | Three decision fields. The model writes none of them. A letter with clinical words does not set `dec-clinical`. Emergency wording still routes to a person |
| INV-03 | A schema-valid booking | Require the approval field | The id’s origin is the document channel. The tool rejects it. A coordinator mints a capability bound to one referral and one action |
| INV-04 | Two texts, or a text for a cancelled visit | A database transaction, or a FIFO queue | The same business key on the crash, the redelivery, and the file replay |
| INV-05 | A correct quotation | Rank, then drop forbidden rows | Filter before score. Citation includes audience and content hash. An edit under the same version id fails |
| INV-06 | A judge that matches the file, and a small comparison that looks like a win | Score with the label present. Ship the higher arm | The scorer cannot see the label. The pre-registered rule on this fixture is no call |
| INV-07 | A green host | Page on CPU and latency | Page when the served document is not the in-force document. The prompt is not in the trace. Shadow traffic cannot write |
| INV-08 | A successful call in a nearby region | Treat the endpoint as the execution place and upload the corpus | Read the processor record. Restricted classes never enter the account, even when the processor region equals the endpoint region |
| INV-09 | A short second desk | Paste the previous column names | The same binding shape. Those names are absent |

INV-04, INV-07, and INV-08 also produce a cloud artifact. The others produce a boundary note: these bytes stay on the laptop, and why.
