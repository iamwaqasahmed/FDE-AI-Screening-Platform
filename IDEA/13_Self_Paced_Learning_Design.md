# 13 — Self-paced learning

## The loop

1. The world is already up. The student sees symptoms.
2. They write a prediction. The checker requires the file and does not grade its wording.
3. The chapter names the mechanism on a different object. If the procedure is new, it works one example on that object.
4. The student submits a binding.
5. The checker runs practice, holdout, and a mini-world. One miss fails. The message names the relationship and withholds the gold value.
6. They may resubmit. There is no token budget and no extra investigation.
7. After a pass, a short hindsight page may use the practice scenario. It still does not contain the holdout.

## What software grades

Field paths, role tags, traces, counts of bookings and messages, citation hashes, template findings, and the absence of restricted fixtures. A missing file fails. A `pass` flag in the model input fails INV-06.

## What software does not grade

Prose quality. Whether a director would be persuaded. Whether the prediction was insightful. Those are not gates.

## A person, if one exists

One recording for the whole course, on a log the student has not seen. Two points: the relationship is named, and a repair that only renames a field is refused. With no person, skip it. Do not block INV-09 on it.

## Orientation, not a lesson

One page maps case labels to real documents without merging them: a personal-data law and its implementing regulation, a national cybersecurity baseline, a government accessibility guide, a cloud provider’s shared-responsibility statement, and a data-classification policy whose restricted examples include a health file and a supplier quotation. The case remains fiction. A sentence that says the exercise “meets” one of those documents fails a review, not a student check.

## Setup

Python 3.12, a virtual environment, and the `access` and `repair` packages. The page is skippable when those already run. It is not INV-01.
