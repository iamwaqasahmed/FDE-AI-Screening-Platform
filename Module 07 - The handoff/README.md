# Module 07 — The handoff

Leave the service with the two people who have to live with it. One scope, two pages, one runbook, and an owner note. The pilot does not start until a clinical safety owner is named.

**Time.** About half a day.
**Pack.** [handoff](../handoff)
**Check.** `python -m screening_handoff.check` from the repository root. No model call.

## Sequence

| | Note | What you do |
|---|---|---|
| 1 | [Two audiences](01-two-audiences.md) | Write one scope for two readers. |
| 2 | [The executive page](02-the-executive-page.md) | Say what the ministry can be shown, and what is deferred. |
| 3 | [The clinical page](03-the-clinical-page.md) | Name the signer. Leave the 14-day rule as a draft. |
| 4 | [The runbook](04-the-runbook.md) | Start, log, failure, and what the service will not do. |
| 5 | [The owner](05-the-owner.md) | No named safety owner means the pilot does not start. |
| 6 | [Check](06-check.md) | Run the checker. |
