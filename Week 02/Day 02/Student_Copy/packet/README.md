This is the file drawer. The lesson is the numbered chapters, starting at [00 — Background](../00-background.md). Do not read the files below as a second assignment.

- [kickoff](kickoff/README.md) holds the standing pages this day still uses.
- [release](release/README.md) holds today's drop.
- [app](app/intake.py) holds the shell. [Chapter 06](../06-the-worker.md) starts with [intake.py](app/intake.py), [cancel.py](app/cancel.py), [registry.py](app/registry.py), and [sms.py](app/sms.py). [Chapter 08](../08-the-mart.md) starts with [mart.py](app/mart.py). Chapter 01 copies the whole folder to `../work`. Leave this copy unchanged. Chapters 06 and 08 replace only `intake.py`, `cancel.py`, and `mart.py` in the work copy.
- [templates](templates/sprint.md) holds the blank pages. The other four are [states.md](templates/states.md), [zones.md](templates/zones.md), [sms.md](templates/sms.md), and [mart.md](templates/mart.md).
- [compose.yaml](compose.yaml) is the laptop stand-in. [Dockerfile](Dockerfile) and [deploy/namespace.yaml](deploy/namespace.yaml) travel with it. A live cluster deploy is a later day.
