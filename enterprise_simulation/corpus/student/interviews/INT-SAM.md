Discovery interview with Sam Nguyen, night file clerk at Cedar Ridge. 12 January 2027.

**Interviewer:** Does Cedar Ridge have an API that can book a slot while the caller is still on the phone?

**Sam Nguyen:** No. There is no slot API. I don't have a button that takes a sentence from Vancouver and turns it into a booking. Cedar Ridge releases a nightly file. That file is the release. If it is not in the file, I have not booked it.

**Interviewer:** Then how does a visit get onto a file at all?

**Sam Nguyen:** I build the file at night and I send it. The file has a name, a night, and the visits I am releasing. People sometimes talk as if the phone call already created the visit. It did not. The file creates the release. I file every night, and that includes Saturday and Sunday. The clinic is not on the Vancouver office week.

**Interviewer:** What time does the file run?

**Sam Nguyen:** 21:00 Pacific. Nine at night, my time. That is when the file goes. I am in Washington. I don't file on a desk clock in Vancouver, and I don't file on a stamp someone converted for a slide. 21:00 Pacific.

**Interviewer:** Does that hold on weekends, or only on nights before an office day?

**Sam Nguyen:** Weekends too. Saturday night is 21:00 Pacific. Sunday night is 21:00 Pacific. I released a Saturday file this month the same way I release a Monday file. The clock does not take the weekend off because the Vancouver office does.

**Interviewer:** If someone shows you a stamp that reads 21:00 with a zone that is not Pacific, what do you file by?

**Sam Nguyen:** I file by Pacific. 21:00 Pacific is the run. If a stamp on a screen has dropped the words and left the digits, they still mean nine at night here. I am not going to refile an hour because a log line looks like it was written in another zone. I was here. The file went at 21:00 Pacific.

**Interviewer:** On REF-4417 the caller said "booked at Cedar Ridge tonight." Is that sentence the file?

**Sam Nguyen:** No. A caller's sentence is not the file. "Booked tonight" is something a person said on the phone. I did not book REF-4417 from that sentence. I will not add a row because Vancouver heard "tonight." The file is the file I release at 21:00 Pacific. The sentence can sit in the call. It is not a slot, and it is not my file.

**Interviewer:** Morgan Ibarra asked to put that sentence on the patient screen before the nightly file landed. Did you add a booking so the screen would have something to show?

**Sam Nguyen:** No. Morgan can ask. I still don't have a slot API, and I still don't book from a sentence. If the screen showed "booked tonight" before my file, the screen was ahead of me. That is the desk. It is not a Cedar Ridge release. I did not backfill REF-4417 to make the sentence true.

**Interviewer:** Which file actually carries REF-4417?

**Sam Nguyen:** `cedar-2027-01-11`. That is the Monday night file. It went out last night at 21:00 Pacific, same as the others. The caller's "tonight" was earlier than that file. I am not going to pretend the sentence and `cedar-2027-01-11` are the same object because they both mention this clinic. The sentence is the caller. The file is what I released.

**Interviewer:** What about Saturday?

**Sam Nguyen:** Saturday I also filed. The Saturday file is `cedar-2027-01-09`. It went at 21:00 Pacific, same rule, weekend included. That Saturday file is not the REF-4417 file. Different night, different file name. I am telling you about it because I counted it, and because Vancouver's list does not match my count.

**Interviewer:** You counted it. Which tally did you put that Saturday file on?

**Sam Nguyen:** The clinic tally. Cedar Ridge. I count the files I actually release, and I release on Saturday. `cedar-2027-01-09` is on my tally. I counted that Saturday file there. I did not leave it off because an office somewhere is closed Saturdays.

**Interviewer:** Did that Saturday file show up on the Vancouver office tally?

**Sam Nguyen:** Not on the tally I was shown. The Vancouver office tally does not have that Saturday file. Their office week is Monday through Friday. My Saturday count is on the clinic tally, and it is absent from theirs. I saw both lists. They do not match on that file.

**Interviewer:** The clinic tally has the Saturday file and the Vancouver office tally does not. Which one is right?

**Sam Nguyen:** I am not declaring that. I counted the Saturday file on the clinic tally. It is not on the Vancouver office tally. Both of those sentences are what I saw. I file the nights, including weekends. They keep an office week. I don't decide which list wins, and I don't want my count rewritten so the two lists agree. Ask someone whose job is the office week if you want a winner. I won't name one.

**Interviewer:** Both numbers are going to be quoted. I need you to say which tally a screen should trust.

**Sam Nguyen:** No. I still won't say who is right. Quoting me as the person who picked a tally would be you putting a verdict in my mouth. The clinic tally has `cedar-2027-01-09`. The Vancouver office tally does not. That is the whole of what I will sign. The 2024 assistant does not get a vote from me either. If the assistant shows a booking the file does not have, the assistant is not my file.

**Interviewer:** Does the facility mart show that Saturday booking?

**Sam Nguyen:** The facility mart has a row for that Saturday, a booking date of 9 January, wait zero, same shape as other mart rows I have been shown. I have seen the mart. It is a real thing on the desk side. My clinic tally also has the Saturday file. Vancouver's office tally does not. I am not going to say the mart makes one of those tallies the true one. The mart can list a booking date. The file I released is still the file. "Booked tonight," said by a caller, is still not the file.

**Interviewer:** The 2024 assistant shows a close of 21:00. Is that your file time, the clinic's closing time, or both?

**Sam Nguyen:** Both. I file at 21:00 Pacific, and 21:00 is the close I work to. The assistant showing 21:00 does not surprise me. That is the night. Weekends included. I am not splitting a close from a file run so someone can have two clocks. Nine at night, Pacific, the file goes, and that is the close.

**Interviewer:** REF-4417's caller said tonight, and you said the file was Monday. If the assistant shows a wait of zero beside that referral, did your Monday file set that zero?

**Sam Nguyen:** I released `cedar-2027-01-11` at 21:00 Pacific. I did not set a wait number, and I did not read the facility mart as my job. The mart can show zero. The assistant can show zero. Neither of those is the sentence "booked tonight," and neither of them is a slot API. I can tell you what I filed and when I filed it. I cannot tell you which tally is the right one, and I am not going to start now because the wait on the mart is zero.
