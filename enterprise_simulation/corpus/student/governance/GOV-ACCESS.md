# Desk rule on screen text, letter files, and break-glass

This page is a desk rule of the Northline Access Collaborative. The desk is in Vancouver, British Columbia. The desk clock is America/Vancouver. The office week is Monday through Friday. A desk rule is an instruction this desk wrote for its own staff. A law is a rule made outside the desk. This page is a desk rule. It is not a law. This page cites no statute. It describes no filing and no external regime. The names on this page are the synthetic names already used in the Northline document room. No real patient, member, or employee is described here. ## Who may read screen text

A clerk may read screen text. Screen text is the text shown on the desk screen for the work the clerk has open. Noel Park, sitting as desk clerk, may read that text during the office week. When another person sits the clerk chair, the same sentence applies to that sitting. The grant follows the desk-clerk role. It is not a private exception written only for one afternoon, and it is not a grant written for every name on the Northline list.

Morgan Ibarra may read screen text when supervising the clerk's screen. Dana Okonkwo may read screen text when directing the desk from that same screen. Reading beside the clerk, on the clerk's screen, is still reading screen text. Standing at the screen does not turn a file into screen text.

This page does not assign Harper a change to the screen, and it does not ask Harper to build a control. This page does not say the assistant or any other live program enforces the rule.

## A letter file is not screen text

A letter file is not screen text. The hospital letter is a file. Words inside the file stay in the file. A screen line that mentions the same referral, the same member, or the same desk does not change the file into screen text. A clerk who may read the screen is not, by that grant, allowed to open the letter file, copy the letter file, or carry the letter file off the desk. The audience mark on the letter is clinician. That mark is part of the file. It is not a clerk grant.

## Break-glass

Break-glass is an opening of a letter file by the on-call physician. Alex Kim, MD, holds that role. An opening on an office day, at night, or on a weekend uses the same sentence. Cedar Ridge may file at night, including Saturday and Sunday. The Vancouver office week does not drop the sentence on those nights.

Break-glass by the on-call physician requires a named reviewer. The reviewer is a person whose name is written as reviewer on that opening. The physician's name records who opened the letter. The name written as reviewer is a separate place on the desk-book line. A reason sentence, a referral reference, a site name, or a blank does not fill that place. The physician's own name, written only as the physician, does not fill that place by itself. This page does not choose the reviewer's name in advance. Being listed anywhere on this page is not itself a review of a later opening.

Alex Kim, MD, writes the opening in the Vancouver desk book at the time of the opening. The line carries the physician's name, the reviewer's name, the letter file that was opened, and the time on the America/Vancouver clock. Morgan Ibarra reads the book on the next office morning. When the reviewer's name is missing, Morgan asks Alex Kim, MD, for the name and writes the answer beside the original line, with the morning's date. The original line stays on the page, so the missing name remains visible until a name is written. That follow-up is a desk practice between Morgan and Alex. This page does not say the live system enforces it. It does not say a program rejects the opening, locks the file, or inserts a reviewer.
