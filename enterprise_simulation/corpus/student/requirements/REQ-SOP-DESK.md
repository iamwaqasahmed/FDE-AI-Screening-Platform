## Where and when the desk works

The desk in this procedure is the Northline desk in Vancouver. The time zone of the desk is America/Vancouver. The office week is Monday through Friday. A patient session is opened on those days only. Saturday and Sunday are not office days at this desk, and a clerk does not open a patient session on either day under this issue.

The office day starts when the supervisor opens the counter and ends when the supervisor closes it. Work that arrives after the Friday close waits for Monday. A night file prepared at Cedar Ridge, or any other clinical site, is not a reason to open the Vancouver counter on a weekend. Cascade Seattle keeps its own records office. This procedure does not move the Vancouver desk onto the Cascade calendar.

The member approaches the counter in person for the factors in this issue. The clerk works from the desk application on the Vancouver counter. The application is not a shared keyboard with a Washington desk. A session opened anywhere else is not a Vancouver session, even when the member, the referral, or the code on a display looks familiar.

## Screen code, then SMS

The factor order is fixed. The first factor is the screen code. The second factor is the SMS. The clerk does not reverse that order, and does not send the SMS before the screen code has been accepted for this approach to the counter.

When the member is at the counter, the clerk asks the member to look at the desk display. The screen code is the code that display shows for this approach. The clerk enters that code with the member present. The clerk does not enter a code remembered from an earlier visit, a code read from a referral sheet, or a code called out by someone who is not at this counter. If the display is blank, the clerk does not invent a code. The approach stops until the display shows a code or the supervisor ends the approach.

The screen code is a factor. It is not the name of the session. Two approaches may show codes that look alike. Likeness of a code does not join the approaches into one session. The clerk treats each accepted screen code as the first factor of the approach now standing at the counter, and then moves to the SMS.

Only after the screen code is accepted does the desk send the SMS. The SMS goes to the handset the member is holding for this approach. The clerk does not read a destination from an old note, and does not ask the member to use a handset that belongs to another person at the counter. The member reads the SMS back so the clerk can enter it. Both factors are required. A screen code without the SMS is not a completed approach. An SMS without the screen code is not a completed approach.

If the SMS does not arrive, the clerk waits the short interval the desk application shows, then asks the supervisor. The clerk does not substitute a code from a previous visit. The clerk does not tell the member that a later clinic step has been completed. The approach remains unfinished until the SMS factor is actually entered.

Evan Cho's rule on these factors is part of this issue. The screen code and the SMS stay with the approach at the counter. The clerk does not copy either factor into a notebook that leaves the desk, and does not repeat them to a caller who is not the member at the counter. When the member steps away from the display, the clerk covers the display. Morgan Ibarra checks that cover during the Monday opening and the Friday close.

## The session id is minted at the desk

The session id is minted at the desk. The Vancouver desk application creates it. Minting happens at the counter, and it happens only after the SMS factor is complete. The screen code alone does not mint a session id. A referral number does not mint one. A hospital file does not mint one. A session already opened at Cascade Seattle, at Cedar Ridge, at Fraser Burnaby, or at any other site does not supply the id.

The clerk does not type the session id. The clerk does not choose it from a list of ids used earlier the same morning. A second approach by the same member, later on the same office day, gets a new session id if the screen code and the SMS are completed again. Familiarity of the screen code is not a reason to reuse an id. If the application fails to mint an id, the clerk does not invent one, and the session is not treated as open. The supervisor records the failed approach and the member is asked to begin again.

The minted session id is the id the clerk writes if a desk note is required while the member is still at the counter. The note names that id and no other. A note about a different member uses the session id minted for that member's own completed factors. The clerk does not repair a note by borrowing an id from a Washington session that happened to show a similar screen code.

## The mart wait may be read to the patient

After the session id has been minted, the member may ask how long the wait has been. The clerk may read the mart wait to the patient. The figure is the mart wait on the facility mart, as that figure is shown for the session. The clerk reads it as the number of days the mart shows. Morgan Ibarra authorizes that reading. Noel Park uses it. Every clerk on the Vancouver desk uses the same reading.

The clerk reads the figure. The clerk does not amend it at the counter, does not average it with a tally kept in a notebook, and does not replace it with a number the member prefers. If the mart wait is not on the screen for that session, the clerk says that the figure is not on the desk and calls the supervisor. The clerk does not compose a substitute number so that the member hears something before leaving.

This reading is the spoken step this issue authorizes. It is not a reading of the hospital letter. Letter text stays off the spoken script at the counter. The clerk does not recite clinical wording, and does not describe the letter, while reading the mart wait. If the member asks for the letter, the clerk takes the name and the session id and refers the question to the supervisor. Priya Shah's clinical record is not fetched to the counter under this issue.

## Close of the office day

At the end of each office day the supervisor confirms three things. Every completed approach has a session id minted at this desk. Every session id written into a note belongs to the approach named in that note. Any mart wait that was read aloud was the figure shown for that session. The Friday close uses the same three checks. The counter then stays shut until Monday. Unfinished approaches are not carried forward by reusing Friday's session ids on Monday morning. Monday begins with new factors and, where those factors complete, with a newly minted session id.
