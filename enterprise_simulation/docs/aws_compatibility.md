# AWS-compatible shape

No AWS account was opened. No stack was applied. `cdk synth` was not run, because this package does not depend on the CDK. The local stand-in is `access.checks.template_policy.scan_template`, which fails a wildcard principal, a public-read ACL, public-access blocking turned off, an `AKIA` access-key prefix, a Bedrock resource type, and `0.0.0.0/0`.

The simulated enterprise stays on the laptop. Restricted bytes (the referral letter, the synthetic national-id file, the procurement quotation, and the wage note) are in `student_pack` and are rejected by the INV-08 checker when a submission uploads them. A call record whose processor region equals `ca-central-1` still does not make the letter uploadable. That check is in `sealed_holdouts.BYTES`, not in the student extracts.

What a later teaching account would hold, matching `IDEA/08_AWS_Implementation.md`, is coordination only: public objects, identifiers, hashes, a queue, a state machine whose payload is ids, a task role, a key, filtered logs, and a budget alarm. It would not hold letters, national identifiers, quotations, wages, gold, or a model resource. SQS standard delivery is at-least-once, which is why `deliver()` is graded on a repeated key. A workflow callback token is not the booking capability graded by `book()`.

Live apply, if a later cohort uses its own account, starts with a budget alarm and ends with a destroy. This repository does not store credentials and does not request that apply.
