# 05 — Tradeoffs, recommendations, and sources

## Recommendation

Split `rel-m04-l05` into three self-paced lessons: connect, twenty-second handoff, evidence-pack decision. Keep the traps and the fictional client. Delete the paste path and the keyword sufficiency tests. Rebuild the five checks so a miss is still a specific sentence, and a pass requires a field, a citation, or a refusal the chapter did not print.

This is **Proven** as a response to the materials in file 01 and the sources in file 02. It is **Emerging** as a grader design until the gold briefings and the reconciliation file exist and `test_m04_l05.py` still proves that counts and attack text stay out of chapters.

## Tradeoffs

**Three lessons versus one afternoon.** Structure A gives each practice a sitting. The cost is a longer module and a facilitator map that currently pairs the drill with the proposal. The course text already says there is no timetable and that one person holds every hat. The classroom trace can keep a single rehearsal day that samples the three lessons. The self-paced path should not sample. Structure B preserves the lesson count and will be shaved back to token checks the moment the chapter is late, unless the paste blocks are gone and the corpus is small. Structure C is the best steady state and a poor first step, because the upstream lessons do not yet teach briefings or baselines.

**Keyword checks versus evidence checks.** The current checks are stable, fast, and explained by miss sentences a learner can repair. They are also the answer key. An evidence check needs author-written gold: briefing fields, leave expectations, a retained benefit id. That gold must live with the grader, as today's gold already does, and the tests must keep it from leaking into chapters. The cost is authoring time. The gain is that a learner can no longer pass by searching chapter 08 for `not the value model`.

**File-order ranking versus a cited score sheet.** File order is reproducible and, on this JSON, yields the course's preferred first problem. It does not survive a reorder, and it does not teach value, feasibility, effort, or impact. A score sheet can be gamed by inventing weights. The control is the citation rule: no citation, no point, blocker forces closed. The gold decision should stay `p-clock` only while the because-clause (the clock poisons the other numbers; identity still blocks the waitlist; triage is clinically blocked) is what the program believes. If that belief changes, change the gold in public. Do not keep a sort that hides the belief.

**Short memo versus a full business case.** A Green Book five-case model is the wrong size for a rehearsal scored as practice inside the architecture component. A token essay is the wrong shape for finance's double-count question. The middle is a register plus a short silent-read memo. People who write more than they code, the audience `roles-and-delivery.md` names, get a real writing task. People who code still have 5A and 5B.

**Handoff schema versus a generative summary.** A generated summary looks like the product and cannot be graded fairly in a self-paced lab without a judge model. File 02's sources do not support an uncalibrated judge. Structured fields against author gold are dull and fair. A later lesson can put a model in the loop after the schema is stable. That is **Experimental** here.

**Assisted channel versus staff change.** Putting both in one Adoption heading produced a phone-callback sentence and no owner. Splitting them across 5B (staff behavior) and 5C (patient channel with a client operator) costs a page and prevents the phone-only token from standing in for adoption.

**Keeping `personal.py`.** It satisfies the assessment-map sentence for the module-4 individual lab, and it repeats Lesson 1. Leaving it graded on proposal day teaches that the capstone's individual skill is string equality on `atk-direct`. Move the graded individual to one briefing and one reconciliation. Keep the attack as a suite smoke if security regression matters on the last day. Update the assessment map when the course files are edited. This research folder does not edit it.

**Tolerant reader versus a schema registry.** Teaching Postel's rule with one extra field is **Proven** and small enough for 5A. A registry with compatibility modes is the trace's advanced line. It belongs as a slice, not as a sixth outcome of proposal day. Skipping it means the syllabus line "messaging systems" stays partly unmet. That is an honest gap. Closing it inside the current chapter 06 paste would be a false close.

**FHIR depth.** Teaching `Appointment.status = cancelled` and the slot side effect is enough integration pattern. Teaching a full scheduling IG, subscriptions, and HL7 v2 mappings is a different course. The trace mentions `int-engine`. Either add a single mapping exercise in 5A (leave event to appointment status, scheduling server is the writer) or delete the bridge from the advanced column until a lesson exists. Naming it and not practicing it is how this capstone got wide.

## Decision

Edit toward structure A. If the module outline cannot grow, edit toward structure B with the same deletions. Do not add a sixth outcome to the current paste day and call it depth. The handoff is a briefing a person can use in twenty seconds. The proposal is a register and a memo that cite what the team measured and refuse to count it twice. The ranking does not open on triage because the blocker is clinical, and the learner has to say that. The forward-deployed engineer leaves the consumer, the schema, and the evidence. The client leaves with the names of the people who own safety, the benefit, and the phone.
