# Module 1 — Prove the approach

You leave with an approach, an intake path, an agent, and a readout you can defend.

Work in order. There is no time limit. Finish a lesson's checks before you open the next one. The course guide is [the learning page](../learning/README.md).

| Lesson | Open | What the lesson is |
| --- | --- | --- |
| 1 | [Arrival](<Lesson 01/Student_Copy/README.md>) | Who asked, an access request, a pipeline that rejects a secret, and two interviews. `rel-m01-l01` |
| 2 | [The approach](<Lesson 02/Student_Copy/README.md>) | Four baselines and an approach memo. Every problem gets a family. `rel-m01-l02` |
| 3 | [Intake](<Lesson 03/Student_Copy/README.md>) | Intake runs from referral.submitted to a held approval. It does not book. `rel-m01-l03` |
| 4 | [The agent](<Lesson 04/Student_Copy/README.md>) | A patient can ask for status and book. A return waits for a person. `rel-m01-l04` |
| 5 | [Score the proof](<Lesson 05/Student_Copy/README.md>) | Score the proof, publish the diagram, and answer steering. `rel-m01-l05` |

When lesson 5 is done, open [Module 2 — Put it in the cluster](<../Module 02/README.md>).
