# 02 — The extracts

The register is [problems.md](sources/release/problems.md). The line beside each id is the symptom. The number you carry forward is a claim, except the four lines a baseline printed.

## What each page contributes

| Page | What it is allowed to support |
| --- | --- |
| [dashboard.md](sources/release/extracts/dashboard.md) | A median of 14 days, and the column `booking_date`. The median is a claim. The column name is a fact |
| [vendor-note.md](sources/release/extracts/vendor-note.md) | Containment of 70 percent on a national pilot that counted 640 chats. The same page says that pilot is not the Al-Waha Health Cluster. The percent is a claim about the pilot |
| [access-costs.md](sources/release/extracts/access-costs.md) | The director's order: no-shows 910000 SAR, returned referrals 510000, empty sessions 230000, and 430 calls for hours and documents. Each figure is a claim |
| [sponsor-ask.md](sources/release/extracts/sponsor-ask.md) | The virtual front desk, including triage, is the program. Claimed impact: 3000000 SAR a year. Both are claims |
| [prices.csv](sources/release/finance/prices.csv) | Unit prices. The optional cost lines use `price.ext_large_per_1k` at 20 SAR and `price.local_per_1k` at 3 SAR |
