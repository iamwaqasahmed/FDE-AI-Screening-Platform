## Which clock starts an SLA?

The clock starts at `referral.submitted`. [pol-sla.md](sources/release/policy/pol-sla.md) says it does not start at booking. The contract names `occurred_at` as that clock time. The due dates in [chapter 04](04-the-note.md) are counted from the date on that field.

## What should a second delivery of the same event do?

A second delivery of the same event id changes nothing. The referral keeps the one approval it already has. The replay row has `apr-ref-110` and no second id. Skipping the event id is what makes that true. Opening `apr-ref-110-2` is the starter's miss.
