# Why measure

A demo shows one question that happened to go well. An evaluation shows the set you promised to get right, including the refusals.

This module runs the Module 04 agent on labeled cases. Each case has a question and the tool, document, and numbers you expect. The scorer does not ask you whether the answer "looked fine."

The practice set in this folder is the one you score to finish. The instructor set in `data/eval` was written against the hidden world. Leave that file unread until you choose the instructor report. You do not need it to finish.

**Finish.** You can say what a labeled case shows that one successful demo does not.
