# Why measure

A demo shows one question that happened to go well. An evaluation shows the set you promised to get right, including the refusals.

This module runs the Module 04 agent on labeled cases. Each case has a question and the tool, document, and numbers you expect. The scorer does not ask you whether the answer "looked fine."

You keep a practice set in this folder. The instructor set in `data/eval` was written against the hidden world. You do not edit it, and you do not need it to finish the practice check.
