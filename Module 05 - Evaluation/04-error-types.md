# Error types

A failed case gets one name, so a later change can be accepted or rejected for a reason.

| `error_type` | When it is used |
|---|---|
| `wrong_join` | A coverage, queue, unfinished, vendor, or letter figure does not match, or the wrong tool was called for a count |
| `draft_treated_as_policy` | The 14-day draft is treated as in force |
| `silent_model_treated_as_healthy` | An empty vendor label is described as healthy or as no disease |
| `letter_invents_diagnosis` | A letter answer adds a diagnosis |
| `missed_refusal` | A diagnosis or an unsigned referral was answered |
| `unsupported` | The instructor case asks for a figure the catalog does not return |

`unsupported` means the catalog has no such figure. The practice check ignores it. The instructor report prints it so you can see the gap.

**Finish.** You can give a failed case one name from the table.
