# Module 2 — Put it in the cluster

You leave with sign-in, feeds, tests, a private-cloud URL, and the Ain change.

Work in order. There is no time limit. Finish a lesson's checks before you open the next one. The course guide is [the learning page](../learning/README.md).

| Lesson | Open | What the lesson is |
| --- | --- | --- |
| 1 | [Sign in](<Lesson 01/Student_Copy/README.md>) | A signed-in patient and a signed-in coordinator can open the assistant. Booking waits. `rel-m02-l01` |
| 2 | [Feeds](<Lesson 02/Student_Copy/README.md>) | Intake and cancellation flow through cluster systems. `rel-m02-l02` |
| 3 | [The receipt](<Lesson 03/Student_Copy/README.md>) | The receipt clock and two usability tasks. `rel-m02-l03` |
| 4 | [Deploy](<Lesson 04/Student_Copy/README.md>) | A private-cloud URL with a health probe and a named model hash. `rel-m02-l04` |
| 5 | [The Ain change](<Lesson 05/Student_Copy/README.md>) | A booking at Ain stays on the nightly file. A live slot is not promised. `rel-m02-l05` |

When lesson 5 is done, open [Module 3 — Make the answers honest](<../Module 03/README.md>).
