# 02 — The sprint

Open the finished [sprint.md](work/sprint.md) and put it beside yours.

[cr-ain.md](sources/release/notices/cr-ain.md) says to sequence the work. The smoke test from Lesson 4 is already done, so it comes first. The change is `cr-ain`. The readout and the retro come after it.

The Order section is one sentence: smoke the URL, then sequence the change, then the readout, then the retro. The word `sequence` sits on that sentence. The check looks for the words smoke, change, readout, and retro, in that order. It uses the first time each word appears. It does not print those four words.

The blank sprint has the heading and an empty section. While that blank is the file that runs, the check says `sprint.md does not sequence the change before the readout`.
