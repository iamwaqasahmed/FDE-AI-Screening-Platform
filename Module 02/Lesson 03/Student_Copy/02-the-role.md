# 02 — The role

[Chapter 00](00-background.md) said which release this is. This chapter is how you behave on the client's site for this release. Nothing is filed yet.

A forward deployed engineer works on the client's problem, inside the client's constraints, and leaves something the client can run and check. On this engagement the client is the Al-Waha Health Cluster. You are with the patient-access service. You hold all five parts yourself.

## The five parts today

| Part | What you will leave |
| --- | --- |
| Lead | The sprint, with the suite before usability sign-off, and the switch on the definition of done |
| AI or data engineer | The fixture note. The journey reads the recorded fixture and asserts the mock state |
| Application engineer | The calendar, the reply schema, the receipt, and the four tests |
| Product manager | `status-short` and `caregiver` finished, with the clause ids |
| Architect | The receipt row and the calendar row on the zone page |

You do these in [chapter 05](05-the-sprint.md), [chapter 06](06-the-calendar.md), [chapter 07](07-the-reply.md), [chapter 08](08-the-receipt.md), and [chapter 09](09-the-pages.md), in that order. [Chapter 10](10-finish.md) files the two answers and runs the checks.

There is no interview today. The checks do not read an interview note. They do not read a Hijri note. The phone-only script stays out of today's table.

## Where today sits

[Chapter 00](00-background.md) names this release. New files arrive on a schedule. You work from this folder. The grader's copy of the same pages is built in chapter 01. You read the copies in `packet/`.

The assistant does not book from chat today. Booking from chat waits.

Coding assistants are allowed on the scripts. [Chapter 07](07-the-reply.md) says what may enter a prompt. The fixture file stays out. [pol-assistant-use.md](packet/kickoff/corpus/pol-assistant-use.md) says the watermark stays out of prompts, tickets, and the work you submit. Do not copy that fixture file into `work/`.
