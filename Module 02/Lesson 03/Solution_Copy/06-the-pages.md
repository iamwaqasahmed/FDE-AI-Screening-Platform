# 06 — The pages

Open the finished pages and put them beside yours.

## Usability

[scripts.jsonl](sources/release/usability/scripts.jsonl) has three lines. `status-short` and `caregiver` are `foundation`. `phone-only` is `advanced`, and its actor is `pop-literacy`. The finished [usability.md](work/usability.md) finishes the two foundation scripts and leaves `phone-only` out.

The columns are `script`, `finished`, and `clause`. Both scripts use `yes`. [access.md](sources/release/standards/access.md) has the four clause ids. `status-short` cites `plain-language` and `named-control`. `caregiver` cites `caregiver-complete` and `one-action`.

The check says `a usability script is unfinished` when a foundation script is missing or the finished cell is not `yes`. It says `an accessibility clause is missing` when one of the four ids is absent. It does not name the script or the clause.

## Definition of done

The check says `the fault is not in the definition of done` when the switch name is missing or the word red is missing. The message does not name the switch.
