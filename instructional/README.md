# Author record

This folder is for the people maintaining the course. It is not a lesson.

Participants start at [../learning/README.md](../learning/README.md), then [Module 1 Lesson 1](<../Module 01/Lesson 01/Student_Copy/README.md>). Leave this folder closed while doing a day. It restates the facilitator day maps, including the mistakes the world is built to invite. Reading it instead of the morning chapters skips the discovery those chapters are written to produce.

| File | What it is |
| --- | --- |
| [Curriculum understanding map](curriculum-understanding-map.md) | What the twenty lessons teach, and which five lessons are each module |
| [Concept progression ledger](concept-progression-ledger.md) | Where each important idea is introduced, explained, applied, and reused |
| [Educational experience audit](educational-experience-audit.md) | Where a solo reader could get lost, and what was changed in the pages |
| [Documentation standards](documentation-standards.md) | How later edits to the chapters should sound |
| [Improvement log](improvement-log.md) | Which files were touched, and what was checked |
| [Content preservation report](content-preservation-report.md) | Evidence the exercises, code, and data were left as they were |
| [Documentation validation report](documentation-validation-report.md) | Link and consistency checks after the edit |
| [Remaining issues](remaining-issues.md) | Problems that were not fixed, because fixing them would change the course |
| [Student journey](student-journey/README.md) | The self-paced simulation record: method, day notes, and the reports |

The student-facing additions live in [../learning](../learning/README.md), in the four release-home pages, and in small sections added to the day chapters. Packet files, Python, datasets, and reference implementations were not edited. The course is four modules and twenty lessons. There is no timetable. Release ids are unchanged.
