# 02 — The sprint

The shell sprint was a heading and an empty Order section. The finished page is [sprint.md](work/sprint.md).

The check reads the page in lowercase and looks for five words in order: notice, then guardrail, then access, then dpia, then request. The finished sentences are:

1. Read the notice and open the breach timeline.
2. Turn on guardrails.
3. Close stale access.
4. Complete the DPIA.
5. Handle the access request and the deletion request.

The last paragraph names the five owners. One person does all five parts. The lead owns the breach timeline. The notice they open is [phi-logs.md](sources/release/notices/phi-logs.md).

A page that puts the request before the notice makes the privacy check say `sprint.md does not open the notice first`. That miss fails only the privacy check.
