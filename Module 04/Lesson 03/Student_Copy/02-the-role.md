# 02 — The role

[Chapter 00](00-background.md) said which release this is. This chapter is how you behave on the client's site for this release. Nothing is filed yet.

A forward deployed engineer works on the client's problem, inside the client's constraints, and leaves something the client can run and check. On this engagement the client is the Al-Waha Health Cluster. You are with the patient-access service. You hold all five parts yourself. One person does all five parts. No team split.

You do not paste a file on this page. There is no heading that starts with Replace.

## The five parts today

| Part | What you will leave |
| --- | --- |
| Lead | The sprint opens the forecast first. A plan at yesterday's price is rejected |
| AI or data engineer | The registered adapters share one process. The batch uses the batched rate. A phi row stays on its adapter. A cached public answer spends no call |
| Application engineer | The scale starts one cold start before the peak |
| Product manager | The campaign backlog finishes inside 48 hours |
| Architect | Chat keeps a reserve on the shared pool. The capacity table records today's price |

You do these in [chapter 05](05-the-sprint.md), [chapter 06](06-the-server.md), [chapter 07](07-the-surge.md), and [chapter 08](08-the-pages.md), in that order. [Chapter 09](09-finish.md) files the two answers and runs the two checks.

The slo check reads [finance.notes.md](work/interviews/finance.notes.md) and [bi-lead.notes.md](work/interviews/bi-lead.notes.md). The question files are not the graded notes. [Chapter 03](03-the-forecast.md) runs the interviews. [Chapter 08](08-the-pages.md) replaces the notes. You do not type into the question files.

## Where today sits

[Chapter 00](00-background.md) names this release. New files arrive on a schedule. You work from this folder. The grader's copy of the same pages is built in chapter 01. You read the copies in `packet/`.

Module 4, Lesson 2 left a board for latency, errors, and tool failures, a timeline that matches the replay, and cached clinic hours that drop when the Ramadan circular changes. A board that only has CPU, or a cache that still serves the old hours, is not done. Today the surge is on the forecast.

A watermarked file copied into `work/` fails the check. The message does not print the watermark. Do not copy a file that carries the mark into `work/`.

The packet copies of `adapters.py`, `batch.py`, `route.py`, `public.py`, `quota.py`, `scale.py`, `price.py`, and `capacity.py` stay the shells. You replace only the work copies. The surge check loads `batch.py`, `route.py`, and `public.py`. The packet tests stay the shell tests. You replace the work copies of the tests in the chapters that replace the matching app files. A second run of the prepare script puts the shell tests back. A filled app beside a shell test fails the suite. A shell app beside a filled test fails the suite. The workflow is copied and not replaced.
