# Packet

This is the file drawer. The lesson is the numbered chapters, starting at [00 — Background](../00-background.md). Do not read the files below as a second assignment.

- [release](release/README.md) holds today's drop.
- [app](app/replicas.py) holds the shell. [Chapter 06](../06-the-sites.md) starts with [replicas.py](app/replicas.py). [Chapter 07](../07-the-outage.md) starts with [breaker.py](app/breaker.py). Chapter 01 copies the whole folder to `../work`. Leave this copy unchanged.
- [tests](tests/test_replicas.py) holds the shell tests. Chapter 01 copies them. Later chapters replace the work copies. The packet copies stay the shell tests. A second run of the prepare script puts the shell tests back. Leave this copy unchanged.
- [templates](templates/sprint.md) holds the blank pages. The others are [failover.md](templates/failover.md), [architecture.md](templates/architecture.md), and [knowledge.md](templates/knowledge.md).
- [interviews/ea.questions.txt](interviews/ea.questions.txt) and [interviews/finance.questions.txt](interviews/finance.questions.txt) are the question files. Chapter 01 copies them. They are not replaced. [interviews/ea.notes.md](interviews/ea.notes.md) and [interviews/finance.notes.md](interviews/finance.notes.md) start blank. [Chapter 08](../08-the-pages.md) replaces the work copies of the notes.
- [.github/workflows/ci.yml](.github/workflows/ci.yml) is the workflow. Chapter 01 copies it. This day does not replace it. Leave this copy unchanged. On Windows, `.github` is hidden. In File Explorer, open View and tick Hidden items. On macOS, in Finder, press Command+Shift+period.
