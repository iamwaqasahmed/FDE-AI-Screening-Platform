# Module 06 — Run it in their environment

Package the agent so the authority can start it, see who asked, and stop it. The data-protection rule is the constraint: stay on the authority network, write an access log, do not train on patient images, and do not put a diagnosis in a generated letter.

The integration is the extract in and a result file out. There is no electronic health record and no API the authority did not offer. Secrets stay out of the repo. The production slice is a container, a repeatable run, logs, and a stop. Not a platform.

This module is ready when a cold start serves a tool call and a retrieval, the access log shows who asked, and patient images are still absent.
