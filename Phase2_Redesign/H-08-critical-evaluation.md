# H — Why this design, and where it breaks

## What changed relative to the twenty lessons

The current course already contains the right traps. Phase 1 checked a set of them in code: the answer key in the memo, the session id equal to the subject, the hybrid ranker that is a status filter, the judge that sees `pass`, the screen that branches on a family label, the file modules whose absence passes, the deploy check that searches for a substring, the surge constants, the drill that returns its own budget.

This design keeps those traps and changes the job around them.

The student inherits a running failure instead of pasting a green file. Two other organizations create a real boundary. AWS is a landing zone with a payload rule, not a second copy of the laptop and not a Bedrock call on clinical text. Gates open on a behavior and a decision. Extension labs hold fusion, Splink, containers, and a live account so the core path stays finishable.

## What changed relative to Phase 1’s own advice

Phase 1’s instructional note said one function and optional subsystems. Taken alone, that produces a student who can refuse a design and cannot repair a workflow. Phase 1’s lesson notes, taken alone, produce thirty small platforms.

The split in document F is the catalog. The pacing review in `tracks/04-depth-versus-pacing` cuts the locks. A strong mixed learner, working alone, is expected to finish 9 to 12 blocking gates. The center is 10: three written decisions and seven running checks. The other pieces stay in the catalog and do not open or close the next lock. Reciprocal rank fusion, Splink, a container, and a live account stay distinction labs. The range is a design judgment. It is not a completion study.

Phase 1 said to keep a single cluster. This phase keeps the cluster and adds the Desk and the Partner, because the missing skill was the boundary. It does not switch the cohort to ports or benefits. Those cases are transfer exams.

## Risks

**Region fiction.** On 30 October 2026 the Regions guide had no Saudi geography. `me-south-1` is Bahrain and `me-central-1` is the UAE. `sa-east-1` is São Paulo. A 15 October 2026 blog still said the first Saudi Region was planned for December and not yet open. Bedrock in those Gulf Regions is not a Kingdom landing: Bahrain had no in-region model, and the UAE’s in-region text models found that day were Nova Lite and Nova Pro. Global profiles, and abuse-detection copies kept in the destination Region, stay off the path.

**Bedrock temptation.** Geographic profiles are easy to describe as “data stays in the region.” The docs say they may process the prompt in another region inside the geography. A lab that uses a profile for anything but a public leaflet teaches the wrong habit.

**Scope.** Thirty-two sequential locks would not be finished. The pacing track says to cut the second environment first: a lesson that grows a full local build and a full AWS build loses the AWS build. One policy-checked template stays. A live apply stays optional. Next, cut a second template dialect and any lab that repeats a mechanism already graded. Blocking gates stop at 12. The letter-refusal, the filter, and the ban on claiming a skipped lab stay.

**Account cost.** A distinction deploy can spend money. The template’s budget alarm is the control. The course must not require an account, and must not store student keys.

**Checker honesty.** Several current checks pass a paste, a missing file, or a copied field. The new checks have to be written to the same standard Phase 1 used when it caught those holes: absence is a fail, the gold value is not in the miss text, and the function under test cannot see the answer key.

**Law.** The case clocks and the case labels are fiction. Orientation pages point at official PDPL, NCA, DGA, and NIST documents. A sentence that says the exercise “meets PDPL” or “meets the ECC” is a failed gate.

**Simulator cost.** An event log, twelve projections, and a gold graph are a product. Document J orders the build so the first gates can ship before the AWS templates exist.

## What would change this recommendation

The pacing dissent is already in document F. Ten locks, not thirty-two. The procurement dissent is in document A. Qitaf does not replace the spine. Its useful finding is in force: a quotation is in the same illustrative restricted tier as a health file, so a non-health case does not make the student bucket safe. The Access Office keeps the clinical refusal and the same payload rule. Quotations, letters, and national identifiers stay on the laptop.

A Kingdom region on the Regions table, with an in-region model the lab can cite, would reopen the model sentence. It would not reopen the payload rule. Until then, the student reads the region list and does not hardcode a code.
