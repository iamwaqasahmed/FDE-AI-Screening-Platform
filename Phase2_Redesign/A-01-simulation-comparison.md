# A — Which enterprise is worth a year of self-paced work

Phase 1 told us to keep Al-Waha and thicken it. This phase treats that as a hypothesis. Five settings were compared against the same test: a student must be able to stop a build, inherit a broken system, meet conflicting owners, survive bad data, refuse a high-stakes automation, prove an answer, and deploy only what a real account is allowed to hold.

## The test

| Requirement | Why it is here |
| --- | --- |
| A decision a person already owns | Clinical urgency, a customs hold, or a benefits denial. The assistant must not take it. |
| An inherited failure | Greenfield tutorials hide the actual FDE job, which is the system that is already wrong. |
| More than one organization | One database is an application. A cluster, a national channel, and a payer are an engagement. |
| A document that changes | Hours, criteria, tariffs, or policy circulars. Retrieval has a version, an audience, and a hash. |
| A number that lies | A warehouse clock, a dashboard, or a mart. The student has to say what the column actually measures. |
| A partner that is down | Insurance, a shipping line, or an identity broker. The booking or the clearance must not wait forever. |
| A file that will not grow an API | Ain’s nightly file, a terminal’s EDI drop, or a legacy extract. |
| Arabic and English, and a phone | A status that matches in three channels. |
| An honest AWS boundary | Regulated payloads stay where the policy puts them. The cloud lab is the coordination plane, the public corpus, and the delivery account. |
| A laptop | The mastery gate runs with no account, no GPU, and no live model in the grader. |

## Five settings

### 1. One health cluster, as the course is now

Al-Waha already has the traps: triage blocked, Friday not a working day, a mart that starts the wait at booking, Ain with no slot API, an unauthorized Ramadan circular, a mother and a newborn who must not merge, a judge that copies `pass`. Phase 1 verified those traps in the checkers.

The limit is the boundary. One cluster never forces the student to decide which organization’s record wins, or which bytes may enter an AWS account. The private cloud in the case is a drawing. It does not become a VPC, an IAM role, or a KMS key.

### 2. Replace health with a port community system

A fictional ports authority, a terminal operator, a shipping line, and customs. The inherited system is a document assistant that extracts bills of lading and proposes a release. The forbidden automation is the hold or the release. Messages are EDI, XML, and files. Volume is high. AWS is a plausible host for a logistics platform in a way that Bedrock-plus-PHI is not.

This setting teaches integration as well as health does, and it teaches cloud with less hypocrisy. It drops the audience the syllabus named. It drops device-safety judgment (SFDA MDS-G010 and the FDA’s four-part clinical decision support line), the PDPL health-data duties, and the contact-center literacy problem the current lessons already aim at. Those are the skills a government health-and-digital cohort will be asked for. A port case can be a second engagement later. It is a weaker first case for this cohort.

### 3. Social benefits eligibility

Appeals, identity, and a score that must not be the decision. Strong “do not automate.” Weaker physical operations, weaker bilingual clinical language, and a political blast radius this course does not need. Set aside.

### 4. Municipal permitting

Inspections, SLAs, documents, payments. Excellent digital-service practice. Thin AI judgment: most of the correct system is a workflow and a rules engine. The model is a distraction. Set aside as the core, and keep the GDS discovery pattern as a method.

### 5. Three organizations around the same access problem

Keep the cluster. Add a **National Desk** (patient channel, not Sehhaty) and a **Coverage Partner** (eligibility, not a real insurer). The student is on the cluster’s delivery team and inherits Vendor Release 0.9, which is already answering patients and already wrong.

This is the recommendation.

The cluster still owns the record, the clinician, and the PHI. The Desk owns the signed-in patient, the phone, and the public leaflets. The Partner owns eligibility and will time out. The assistant the vendor shipped calls all three and writes as if they were one database. The student’s job is to find that, refuse the parts that must stay human, repair the workflow locally, and move only the Desk’s coordination plane and the public corpus into an AWS account.

## Why this beats “more Al-Waha” and “a new industry”

More features inside one hospital repeat Phase 1. A new industry throws away traps that were checked against real code. The three-party inheritance keeps those traps and adds the missing FDE move: **whose system is allowed to say this, and whose cloud is allowed to store it.**

AWS is an honest host for the Desk’s non-clinical plane: public hours after they are classified public, appointment reminders that carry no national id, CI, logs with identifiers stripped, and a file inbox. AWS is the wrong host for the referral letter, the national id, and a model call that contains either. The course grades that refusal. A port case would let more of the solution sit in AWS, and would teach a softer version of the same refusal.

## What the case date allows

The engagement in the existing course opens on 10 January 2027. Amazon has said the first AWS region in the Kingdom is on track for December 2026, with three Availability Zones, and that location alone does not establish compliance. As of 30 October 2026 the pages opened for this note do not show the region as generally available and do not publish a region code. The labs must not hardcode one.

In the fiction, the Desk’s landing zone uses the Kingdom region if the account’s region list contains it on the day of the lab. Otherwise the lab deploys in the Middle East region the account actually offers, and the DPIA records that as an exception. Bedrock geographic and global profiles are a fail when the rule is “this text stays in one region.” Official Bedrock docs say in-region invocation is the strict option, and that a geographic profile may process the prompt in another region inside that geography. The geography list opened for this note does not include a Kingdom geography.

## The procurement challenge

A later track argued for replacing the spine with Qitaf, a fictional facilities agency, because a student account that receives referral text is the thing the health case forbids, and a drawing of a private cloud leaves AWS as a logo. The runner-up was a municipal permit desk. The notes are in `tracks/01-kill-or-keep-the-health-case`.

The classification fact is adopted. The NDMO examples opened for that track place supplier quotations and bid submissions in the same illustrative restricted tier as the individual health file and the national identifier. NCA cloud levels are a different vocabulary and are not merged with those names. Leaving the hospital does not make a student bucket a lawful home for the work object. Qitaf is honest only while the quotation never enters the account. That is the same payload rule this design already uses for the letter, the national id, and the wage.

The spine stays the Access Office. The forbidden act is sharper for this cohort: the assistant must not assign clinical urgency, must not book from a letter, and must not confirm a slot the nightly file has not released. A tender score is a real refusal and a weaker life-safety lesson. The track says so about its own alternate. The verified traps in the current checkers are health-shaped. A new agency would reset them.

AWS in this design is the public specification, the id-only workflow, the key, the queue, the trail, and the budget. It is the same short list Qitaf would have been allowed to host. The letter stays on the laptop. Uploading it so the cloud demo looks real fails the gate. That is the condition on which the track said its own winner should be rejected.

## Rejected shortcuts

A single FHIR server that already contains every hospital. That deletes the identity lesson. A Synthea population as the corpus. Phase 1 showed Synthea’s outcome rates do not match the operational mess this course needs. A LocalStack account as a prerequisite. The Testcontainers note dated 23 March 2026 says the image expects an auth token. A live model inside the grader. The same submission would score differently after a weight change, and the hidden answer can leak.
