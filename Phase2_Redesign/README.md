# Phase 2 — Redesign blueprint

This folder is a new design. It does not replace the twenty lessons, the simulator, or the `Idea_*` research.

The recommendation is an inherited, already-broken access assistant that sits between three organizations. The student learns to stop, to repair one workflow locally, and to keep regulated text off AWS. On 30 October 2026 the Regions guide had no Saudi geography. Bahrain and the UAE are other countries. Bedrock is off the path.
