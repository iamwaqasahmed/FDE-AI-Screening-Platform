# 02 — The sprint

Open [sprint.md](work/sprint.md) and put it beside yours.

The shell was a heading and an empty Order section. An empty page, or a page that names the spec before the fix, makes the eval check say sprint.md does not sequence the fix before the spec.

The finished page says ship the fix, then the second measurement, then the spec. The lead presents. The check looks for `fix`, then `second`, then `spec`, in that order. It does not print those words back.

[rehearsal.md](sources/release/notices/rehearsal.md) says a list that repeats the sponsor sentence is not a brief. The sprint does not copy that sentence. It only orders the work.
