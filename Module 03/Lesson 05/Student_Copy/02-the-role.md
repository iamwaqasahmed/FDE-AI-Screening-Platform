# 02 — The role

[Chapter 00](00-background.md) said which release this is. This chapter is how you behave on the client's site for this release. Nothing is filed yet.

A forward deployed engineer works on the client's problem, inside the client's constraints, and leaves something the client can run and check. On this engagement the client is the Al-Waha Health Cluster. You are with the patient-access service. You hold all five parts yourself.

## The five parts today

| Part | What you will leave |
| --- | --- |
| Lead | The sprint: the fix, then the second measurement, then the spec. The lead presents |
| AI or data engineer | One repaired citation, a second run that moves the retrieval failure, a label cost, and a personal citation that keeps version and audience |
| Application engineer | A backlog that drops the non-goals, a citation requirement on the risk tier, and an uncommented improvement gate |
| Product manager | The rehearsal brief: triage is a non-goal, the dot-vote is not the value model, and a clinician owns urgency |
| Architect | The benchmark, the improvement plan, the readout, the retro, and the two knowledge answers |

You do these in [chapter 05](05-the-sprint.md), [chapter 06](06-the-fix.md), [chapter 07](07-the-spec.md), [chapter 08](08-the-personal.md), and [chapter 09](09-the-pages.md), in that order. [Chapter 10](10-finish.md) files the two answers and runs the four checks.

The checks do not read an interview. You do not run an interview command, and you do not write interview notes.
