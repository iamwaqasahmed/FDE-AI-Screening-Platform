# 06 — The pages

Open the finished [patients.md](work/patients.md) and [classes.md](work/classes.md) and put them beside yours.

## One patient

The identity check reads `patients.md`. One patient is not one row, not one MRN, and not one national id. A mother and a newborn stay apart. Twins stay apart. A reused MRN stays two people.

The check looks for `row`, `mrn`, `national`, `mother`, `newborn`, `twin`, and a word that starts with `reus`. It does not name which word was missing. While the blank is the file that runs, the check says `patients.md does not define one patient`. The page does not store a national id value. The shared id stays in the history file and on the demo.

## Classes

The synthetic check reads `classes.md`. The table header contains field and class. The pipe characters stay, so a copy keeps the shape the check reads. National id, date of birth, name, and phone are each class phi. The note says the synthetic file was scanned before it was shared. The word `scan` is required. The field name `national id` is not a value from the history.

While the blank is the file that runs, or a pipe is missing, the check says `the classification note is missing`. The message does not name the missing cell.
