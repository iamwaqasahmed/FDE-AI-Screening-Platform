# Module 3 — Make the answers honest

You leave with honest labels, a registered adapter, citations, a measurement, and requirements.

Work in order. There is no time limit. Finish a lesson's checks before you open the next one. The course guide is [the learning page](../learning/README.md).

| Lesson | Open | What the lesson is |
| --- | --- | --- |
| 1 | [Honest data](<Lesson 01/Student_Copy/README.md>) | One person, labels that follow the current guideline, and a synthetic sample. `rel-m03-l01` |
| 2 | [The adapter](<Lesson 02/Student_Copy/README.md>) | A registered adapter inside the quota. The external fine-tune is closed. `rel-m03-l02` |
| 3 | [Cite](<Lesson 03/Student_Copy/README.md>) | Cite an in-force document the asker is allowed to see. `rel-m03-l03` |
| 4 | [Measure](<Lesson 04/Student_Copy/README.md>) | A draft benchmark that names the planted failures. `rel-m03-l04` |
| 5 | [One fix](<Lesson 05/Student_Copy/README.md>) | One remeasured improvement, and requirements a later team could start from. `rel-m03-l05` |

When lesson 5 is done, open [Module 4 — Run it](<../Module 04/README.md>).
