# 05 — The advanced path

Open the finished files and put them beside yours. The three checks do not require these files. You still replace them. You do not delete them. When the files are present, they keep the behavior the suite already compares.

## Photo

[vision.py](work/app/vision.py). The shell returns the export and skips the transcription. The filled file removes the export from the transcription and keeps what remains. `export` is still in the file. That is expected. The photo fields are in [prep.json](sources/release/photos/prep.json). Do not type the leftover sentence into a note. The demo does not print it.

## Booking

[conflict.py](work/app/conflict.py). The shell lets the facility window replace the cluster window and leaves the other name empty. The filled file names the site document and names [pol-booking-cluster.md](sources/release/dms/pol-booking-cluster.md) as the winner. The facility page is [pol-booking-h-safra.md](sources/release/dms/pol-booking-h-safra.md). Search that file for `h-safra`.

## Catalog

[catalog.py](work/app/catalog.py). The shell cites a leaflet and leaves the prep empty. The filled file returns the clinic and the prep from [service-catalog.json](sources/release/catalog/service-catalog.json). It does not carry a document id. You should not see `Cite the leaflet instead`.

The suite, from `Solution_Copy/work`, prints `Ran 14 tests` and then `OK`. The same tests beside the packet shells fail. Do not edit a test. The eleven test files match the packet byte for byte.
