# Grade-code list

Status: In force.

These are the only codes a grader result may use.

| Code | Meaning | Referral box |
|---|---|---|
| R0 | No diabetic retinopathy seen | blank |
| R1 | Mild disease that is not referable | blank |
| R2 | Referable disease that is not sight-threatening | yes |
| R3 | Sight-threatening disease | yes |
| U | Photo could not be read | blank |

Free text such as "prolif" or "urgent" is not a code on this list. If a sheet uses those words, a careful reading maps them to R3 only when the note or the code clearly means sight-threatening disease.

A blank result and a blank note means the screen is unfinished. It does not mean the eye was normal.
