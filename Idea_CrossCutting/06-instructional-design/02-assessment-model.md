# Assessment model

The current map already has the right skeleton. Foundation checks are the pass line. A failed foundation check cannot receive a distinction. Advanced checks add evidence up to a component ceiling. The grading service returns pass or fail per check id and does not return expected answers. Written work is described on four dimensions: must-mention, must-not-claim, traceability, and boundary. Knowledge questions are complete or not, and they do not require a team repository. Steering readouts use a facilitator sheet.

Two uses of those scores are doing more work than the evidence can support. A green run of a pasted file is being asked to stand for judgment. A target of 80% of the gold facts in a document is being asked to stand for architectural and professional quality. [Kane (2013)](https://doi.org/10.1111/jedm.12000) is the constraint: validity belongs to an interpretation and a use, not to the check. A more ambitious claim needs more support. Negative consequences of a use can make that use unacceptable even when a narrower reading of the same score is sound.

| Score | Interpretation that can be supported | Use it should not be given |
| --- | --- | --- |
| A behavioral check on a file the learner completed or labeled | This artifact meets the named behavior in this simulation | The learner can design the next subsystem, or explain the boundary under questioning |
| A pasted file that matches the chapter | The file in `work/` behaves as the chapter's file behaves | The learner studied it or could produce it |
| Must-not-claim, when the banned sentence is enumerable | This text does not contain that sentence | The learner holds no equivalent claim in other words |
| An id that exists in the case or in the learner's outputs | The citation pointer resolves | The claim is warranted, proportionate, or clear |
| A canary or residency log | This run did not show that breach | The learner's DPIA is ethically adequate |
| A recorded steering answer, scored with a rubric against exemplars | A reviewer judged this answer to meet the readout specifications | An automatic transcript score means the same thing |

## Mastery gates as specifications

[Bloom (1968)](https://eric.ed.gov/?id=ED053419) framed mastery as a definition of what mastery is, plus instruction that can vary, with time as the variable that absorbs differences in aptitude. Most of the argument is that the criterion is set and the calendar is not the criterion. [Kulik, Kulik, and Bangert-Drowns (1990)](https://doi.org/10.3102/00346543060002265) found achievement gains, especially for weaker students, more time on task, and lower completion for self-paced college mastery programs. Small specifications and revision are how this course takes the gain without copying the completion failure. A large gate, repeated twenty times, is the failure mode.

[Nilson's specifications grading](https://doi.org/10.4324/9781003447061) is the higher-education form used here: each assignment is met or not yet against a single clear level, revision is allowed, and a higher standing is a bundle of additional work rather than partial credit. [Howitz, McKnelly, and Link (2025)](https://doi.org/10.3390/educsci15010083) reviewed 90 implementations and found the published record still talking mainly about instructor time, performance, and student reaction. That is not a settled effect size. [Fernandez, Martin, Mangum, and Bell-Huff (2020)](https://peer.asee.org/whose-grade-is-it-anyway-transitioning-engineering-courses-to-an-evidence-based-specifications-grading-system.pdf) document the move in engineering courses as a faculty practice, not as a controlled learning trial. An institutional report from Carnegie Mellon's Eberly Center, covering courses from fall 2023 through spring 2025, [found no difference in performance or grade distribution](https://www.cmu.edu/teaching/teaching-as-research/atscale/specgrading/index.html). On four post-survey items, including clarity about how the grade was earned and how assignments were graded, students in the traditionally graded courses responded more positively. The lesson for this course is narrow. Binary specifications help only when the specification is clearer than the judgment it replaces. An 80% gold-fact rule is a points system in a pass/fail costume. Learners cannot see which missing sentence matters.

### Bundles

| Bundle | What "met" means | What opens next |
| --- | --- | --- |
| Core specification | The decision specs for that lesson, including any single completion the decision requires | The next core lesson |
| Module gate | The lesson-5 core specs for that module, including the readout | The next module's first lesson |
| Implementation specification | The extension lab's behavioral check | Nothing on the core path. It unlocks claims in the capstone |
| Distinction | The core gates plus the implementation bundle the cohort publishes, and a readout above the pass line | A distinction record. This note does not set the cut |

Core specifications may be revised until they are met. A token limit fits a semester. Here it would recreate the Kulik completion problem on the only path. A cap, if a cohort needs one, belongs on optional distinction attempts.

The assessment map's rule stands: a failed foundation specification cannot receive a distinction. Extend it one step. A failed core specification cannot open the next core lesson. An unmet extension lab does not do that.

## Judging judgment

[Sadler (1989)](https://doi.org/10.1007/BF00117714) distinguishes correct/incorrect responses from qualitative judgments that use several criteria. For the second kind, feedback works when the learner has a concept of quality, can compare their own work with it, and has a move that closes the gap. A keyword ratio does not supply the concept of quality. Exemplars do: one passing decision record and one failing one, shown before the learner writes, with the difference stated as a specification.

Replace must-mention-at-80% with a short decision list. Each line is met or not yet. The list is the specification, published in the chapter, and it is short enough to hold in mind. Across the written artifacts the list is the same four kinds of line the map already cares about, rewritten so each can be applied by a person the same way twice.

| Specification | Met when |
| --- | --- |
| Decision | The required refusal or commitment is present and matches the case constraint for this lesson |
| Banned claim | None of the named banned claims appears. One banned claim fails the artifact. Paraphrase is judged by a person at module gates, not by a substring at every lesson |
| Trace | Each claim points at a file id, a persona id, or a measurement that exists in what this learner produced or was given |
| Boundary | Clinical urgency stays with a clinician. PHI stays off `ext-large`. The lesson's local boundary is named in the same sentence style |

Trace pointers can be checked by software when the id is a literal. The warrant behind the pointer cannot. Banned-sentence scanners are a floor. They miss paraphrase and they false-fail quotations that discuss the ban. A scanner may return not-yet. It may not return the official pass on a design, a DPIA, or a proposal.

### Asynchronous oral

The current readout is a facilitator sheet filled in a live steering session. That session will not exist for every self-paced learner. A recording can carry the same questions (`steer-m01` through `steer-m04-l05`) if the reliability problem is faced directly.

[Akimov and Malin (2020)](https://doi.org/10.1080/02602938.2020.1730301) studied live oral exams online. They treat validity as the stronger property and reliability as the weaker one: another question, another occasion, or another examiner can change the result. They cite the practical point that follow-up questions are what separate a rehearsed surface answer from an answer the learner can extend. A single uploaded monologue drops that property.

The module gate and the capstone therefore use two recordings. The learner sees the rubric and the exemplars first. They record an answer to one steering question. After that file is saved, the chapter reveals one scripted follow-up tied to the lesson's trap, and they record the second answer. A delayed reviewer scores both against the rubric. A second reviewer scores a sample that includes high, middle, and low results, which is the moderation pattern Akimov and Malin used. Early work on fully asynchronous orals, such as the account summarized at [doi:10.1007/s11423-026-10677-0](https://doi.org/10.1007/s11423-026-10677-0), suggests students prepare differently and that scores are not interchangeable with multiple-choice exams. That is a reason to use recordings as a complement. It is not a reason to auto-score them.

The learner's own markup of their answer against the exemplar is practice in Sadler's comparison skill. It is not the official score. Software that grades the prose and writes the missing gold claim into the feedback is the answer key, delivered sideways.

## Feedback with no live instructor

[Shute (2008)](https://doi.org/10.3102/0034654307313795) summarizes formative feedback as information aimed at the task, specific, and elaborated in pieces small enough to use. Verification alone is weaker than an explanation of what, how, and why. Too much explanation is discarded and adds load. The finish chapters already name the failing line and the chapter to reopen, and they withhold the expected answer. Keep that. Shape it into four messages, each one unit.

| Moment | Message | Withheld |
| --- | --- | --- |
| Prediction saved | The consolidation chapter for that trap: the case consequence of this fork | The gold file |
| Check returns not-yet | The unmet specification, in the words of the spec, and the chapter that owns it | The corrected file and the gold sentence |
| Hint rung 1 | A question that points at the refusal | Any fact the learner was meant to commit |
| Hint rung 2 | A partial decision, analogous to a completion | The finished paragraph or function |
| Hint rung 3 | The policy, fixture, or file to open | A gold value, as the current hint rule already requires |
| Specification met | The solution chapter beside the learner's artifact, and a prompt to write the four beats | A second, richer answer to paste over `knowledge.md` |

The three rungs already in the lesson template are the procedural information of the four-component model. They fade. Later lessons do not repeat the paste lecture. Rung 3 still does not contain the gold value.

After a pass, the solution is feedback, which is a different event from the worked example that opens a procedural lab. Conceptual traps keep the solution closed until the prediction exists and the check has run. Procedural labs show the example or the completion before the attempt. Both end with the same study note: the four beats, in the learner's sentences, stored where the gate can see that they exist and that they name the refusal. Quality of those sentences is reviewed at the module recording, not substring-matched on the lesson.

## What automated checks can grade

- Executable behavior in this simulation: a secret is rejected, a health response is up, a tool does not book from a sentence inside a letter, a test goes red when the seeded fault is on, an unauthorized document is not returned as a citation, a named store no longer holds a deleted record, a health hash is the named hash.
- Structure: a required file exists, a required heading exists, a problem id is present, a prediction file's timestamp is before the consolidation was opened.
- Literal traceability: a cited id resolves to a real file, persona, or measurement.
- A conservative scan for a banned literal, used only as not-yet.
- Conduct events the assessment map already logs: an unexplained canary hit, a residency breach.

## What they cannot grade

- Whether the prose would survive a hostile question, including paraphrase of a banned claim.
- Architecture as a trade-off: what is not built, coupling, operability, and whether the human step is real or decorative. A diagram check can require a human node. It cannot require that the node is the right one for a reason.
- Ethical reasoning. The DPIA's proportionality, the residual risk, and the fairness account are qualitative judgments in Sadler's sense. The conduct log supports a narrower claim, the one the certification table already uses: no unexplained breach on the runs submitted.
- Professional communication: whether a director would understand the readout. That is the recording plus the rubric.
- Self-explanation quality at lesson scale, beyond "the four beats are present and name the refusal."
- Transfer to a later real client. The map already keeps that 25% outside this case. This model does not pull it back in.

A check that can grade a behavior should grade that behavior, on the bundle that owns it. The core bundle owns the decision. The implementation bundle owns the subsystem. Using one to stand for the other is the validity error this model is built to avoid.
