# Idea: Module 01 Lesson 04 — The agent

Research for `rel-m01-l04`. These notes do not replace `Student_Copy`, `Solution_Copy`, or the checks.

**Thesis.** Patient-access booking is a dialogue policy, an allowlisted tool server, and a capability the coordinator mints. A general tool-calling loop, where the model discovers tools and chooses writes, is the wrong production shape. MCP, A2A, LangGraph, the OpenAI Agents SDK, PydanticAI, and Google ADK supply wiring, pauses, and schemas. The booking rule stays in application code.
