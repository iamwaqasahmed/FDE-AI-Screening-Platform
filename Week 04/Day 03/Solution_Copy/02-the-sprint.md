# 02 — The sprint

[sprint.md](work/sprint.md) opens the forecast, then the server, then the batch, then the quota, then the scale, then the capacity table. The AI engineer owns the server settings. The application engineer owns the scaler. The architect splits the quota. The product manager checks the forecast. The lead rejects a stale price.

The shell page has an empty Order section. An empty page, or a page that names a later word first, makes the slo check say `sprint.md does not open the forecast first`. A sprint miss fails only the slo check.

[README.md](sources/release/README.md) says today's external price replaces yesterday's `price.ext_large_per_1k`. Do not copy the rate. [p-forecast.json](sources/release/forecast/p-forecast.json) names the eye-screening campaign. Do not copy the backlog count or the peak time.
