# Packet

This is the file drawer. The lesson is the numbered chapters, starting at [00 — Background](../00-background.md). Do not read the files below as a second assignment.

- [release](release/README.md) holds today's drop.
- [app](app/adapters.py) holds the shell. [Chapter 06](../06-the-server.md) starts with [adapters.py](app/adapters.py). [Chapter 07](../07-the-surge.md) starts with [quota.py](app/quota.py). Chapter 01 copies the whole folder to `../work`. Leave this copy unchanged.

- [templates](templates/sprint.md) holds the blank pages. The others are [capacity.md](templates/capacity.md) and [knowledge.md](templates/knowledge.md).
- [interviews/finance.questions.txt](interviews/finance.questions.txt) and [interviews/bi-lead.questions.txt](interviews/bi-lead.questions.txt) are the question files. Chapter 01 copies them. [Chapter 08](../08-the-pages.md) replaces the work copies of the notes.
- [.github/workflows/ci.yml](.github/workflows/ci.yml) is the workflow. Chapter 01 copies it. This day does not replace it. Leave this copy unchanged. On Windows, `.github` is hidden. In File Explorer, open View and tick Hidden items. On macOS, in Finder, press Command+Shift+period.
