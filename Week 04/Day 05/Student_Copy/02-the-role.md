# 02 — The role

[Chapter 00](00-background.md) said what the four weeks produce. This chapter is how you behave on the client's site today. Nothing is filed yet.

A forward deployed engineer works on the client's problem, inside the client's constraints, and leaves something the client can run and check. On this engagement the client is the Al-Waha Health Cluster. You are with the patient-access service. You hold all five parts yourself. One person does all five parts. No team split.

You do not paste a file on this page. There is no heading that starts with Replace.

## The five parts today

| Part | What you will leave |
| --- | --- |
| Lead | The sprint opens the requests first. You present the proposal |
| AI or data engineer | The success metrics name site-b and a problem you already measured |
| Application engineer | Staff sign-in holds. The bus stays up. A handoff has a summary. Late leave cancels the session. The warehouse clock is not the booking date |
| Product manager | The ranking says the dot-vote is not the value model. The roadmap does not start with triage |
| Architect | The deployment architecture and the operations plan are both filled. The proposal can be presented |

You do these in [chapter 05](05-the-sprint.md), [chapter 06](06-the-connections.md), [chapter 07](07-the-proposal.md), and [chapter 08](08-the-pages.md), in that order. [Chapter 09](09-finish.md) files the two answers and runs the five checks.

The integrate check reads [access-mgr.notes.md](work/interviews/access-mgr.notes.md) and [ea.notes.md](work/interviews/ea.notes.md). The question files are not the graded notes. [Chapter 03](03-the-requests.md) runs the interviews. [Chapter 08](08-the-pages.md) replaces the notes. You do not type into the question files.
