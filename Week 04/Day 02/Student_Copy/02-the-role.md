# 02 — The role

[Chapter 00](00-background.md) said what the four weeks produce. This chapter is how you behave on the client's site today. Nothing is filed yet.

A forward deployed engineer works on the client's problem, inside the client's constraints, and leaves something the client can run and check. On this engagement the client is the Al-Waha Health Cluster. You are with the patient-access service. You hold all five parts yourself. One person does all five parts. No team split.

You do not paste a file on this page. There is no heading that starts with Replace.

## The five parts today

| Part | What you will leave |
| --- | --- |
| Lead | The sprint opens the replay first. The timeline matches that replay |
| AI or data engineer | A span keeps the tool, the hash, and the token count. Each drift has its own name |
| Application engineer | The board names latency, errors, and tool failures. Every hospital is in the cost. Cached hours drop when the Ramadan circular changes |
| Product manager | The override rate is the stamped share |
| Architect | Shadow traffic keeps the registered reply. The runbook names detection, scope, impact, the timeline, the owner, the cache, and shadow |

You do these in [chapter 05](05-the-sprint.md), [chapter 06](06-the-board.md), [chapter 07](07-the-hours.md), and [chapter 08](08-the-pages.md), in that order. [Chapter 09](09-finish.md) files the two answers and runs the two checks.

The incident check reads [ciso.notes.md](work/interviews/ciso.notes.md) and [patient-rep.notes.md](work/interviews/patient-rep.notes.md). The question files are not the graded notes. [Chapter 03](03-the-replay.md) runs the interviews. [Chapter 08](08-the-pages.md) replaces the notes. You do not type into the question files.

## Where today sits

Week 4 Day 1 left guardrails on, stale access closed, a filled DPIA, and one access request and one deletion request handled. A suite that only blocks a direct ignore phrase, or a deletion that clears the row and leaves the index, is not done. Today the replay is open.

A watermarked file copied into `work/` fails the check. The message does not print the watermark. Do not copy a file that carries the mark into `work/`.

A filled app beside a shell test fails the suite. A shell app beside a filled test fails the suite. The workflow is copied and not replaced.
