# 02 — The sprint

[sprint.md](work/sprint.md) opens the replay, then the dashboard, then the timeline, then the cache, then shadow. The lead owns the timeline. The AI engineer reads the traces. The application engineer owns the dashboard. The product manager computes the override rate. The architect writes the runbook.

The shell page has an empty Order section. An empty page, or a page that names a later word first, makes the incident check say `sprint.md does not open the replay first`. A sprint miss fails only the incident check.

[README.md](sources/release/README.md) says the incident replay is open. [note.md](sources/release/replay/note.md) says the alert is already in the spans.
