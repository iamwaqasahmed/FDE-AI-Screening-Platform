# Module 08 — Capstone

A new ask arrives on the same authority. No new data. The ask might be to add breast screening, to deploy River Outreach next, or to treat the 14-day draft as policy because the quarter is ending.

You run the Module 01 moves in short form. Then you say what the tools and the agent can take, what they must refuse, and what would have to be true before a second slice. You do not rebuild the platform.

This module is ready when the recommendation is a smaller slice or a refusal with a reason, and it cites the files and rules already in the program.
