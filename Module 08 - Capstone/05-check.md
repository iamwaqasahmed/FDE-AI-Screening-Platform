# Check

From the repository root:

```text
python -m screening_capstone.check
```

The checker reads the three recommendations in [capstone](../capstone). It does not call a model and it does not read `data/truth`.

Each note must refuse or phase the ask, cite a file already in the program, and not tell you to rebuild the platform or to start the pilot.
