# The new ask

You already have an eye-screening agent, a retriever, a service, and a handoff pack. The pilot has not started, because the clinical safety owner is unassigned.

A new ask does not get a new platform. For each ask, write four lines:

1. The ask, in their words.
2. What the existing tools and agent can take.
3. What they must refuse, and which file is the reason.
4. What would have to be true before a second slice.

Use the corpus, the clinic note, the data-protection rule, and [handoff/owner.md](../handoff/owner.md). Do not generate a new extract.
