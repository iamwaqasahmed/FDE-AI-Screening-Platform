# Screening capstone

Checker for the reference notes in [Module 08](../README.md). Your four-line comparisons stay with you. This checker reads the reference pack.

Checks three recommendations on the same Hartland data. It does not call a model and it does not read `data/truth`.

Each note in [capstone](../../capstone) refuses the new ask, cites a file already in the program, and does not rebuild the platform or start the pilot. Breast screening and River Outreach cite the clinic note. The 14-day ask cites the draft procedure and the unassigned clinical safety owner.

The lesson is [Module 08](../README.md).

From the repository root:

```text
python -m course screening_capstone.check
```
